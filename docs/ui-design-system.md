# Gang Chat UI 设计规范（Signal）

本文档描述客户端当前的视觉语言与信息架构。界面代码只通过
`lib/src/ui/tokens.dart` 中的 token 取色、圆角、字体、阴影和动效，不在
feature 代码里写死颜色值。

## 1. 设计理念

Signal 把客户端当成一台"信号接收器"：纯黑的点阵画布上，只有正在发生的
事情（语音直播、未读、可执行的操作）会亮起酸橙色。

1. **黑底点阵**：窗口画布是近乎纯黑的 `background`，铺一层极淡的点阵
   （`DotGridBackground`）。内容放在大圆角的深灰卡片上，卡片之间靠明度区分。
2. **一种信号色**：酸橙绿 `accent #D4FF3F` 只表示"活的、可以按的"——
   直播中、主操作按钮、发送、在线、未读计数。不要拿它做装饰。
3. **反色即选中**：当前选中的标签、分段、导航项用白底黑字的反色胶囊
   （`UiColors.inverse`），不用强调色表示选中。
4. **三种字体各司其职**：
   - Space Grotesk（`kDisplayFontFamily`）：标题、名称等展示性文字；
   - JetBrains Mono（`kMonoFontFamily`）：大写小标签、时间戳、计数说明；
   - Doto（`kDotFontFamily`）：点阵数字与品牌字标 `GANG CHAT`。
   中文始终回落到客户端默认字体。
5. **扁平**：不使用立体底座；可按压元素只在悬停时变亮、按下时变暗。只有
   浮层（菜单、弹窗、Toast、面板）带阴影。
6. **人圆房方**：用户头像是圆形；房间头像是圆角方形（`Avatar(rounded: true)`）。

## 2. Token

### 颜色（由暗到亮）

| Token | 值 | 用途 |
| --- | --- | --- |
| `surfacePressed` | `#000000` | 轨道、凹陷区 |
| `background` | `#060607` | 窗口画布（点阵底） |
| `surfaceLow` | `#0D0D0F` | 内容面板、设置页、弹窗 |
| `card` | `#131316` | 面板内的分组卡片、便当格 |
| `surface` | `#17171A` | 列表项、按钮底色 |
| `surfaceRaised` | `#1E1E22` | 菜单、浮层 |
| `surfaceHover` | `#27272C` | 悬停 |
| `border` / `borderStrong` | `#222226` / `#323238` | 发丝线 |

强调与状态：`accent`（酸橙，文字/填充通用）、`onAccent`（酸橙上的深色字）、
`inverse` / `onInverse`（反色选中）、`selected` / `accentBorder` /
`selectedBorder`（带酸橙倾向的选中底与边框）。

语义色：`success`（= 酸橙）、`danger #FF4D4F`、`amber #FFB224`（@我、警告）、
`presence*`、`role*`。

### 形状

`UiRadii`：xs 5 · sm 8 · md 12 · lg 18 · xl 26 · pill 999。
按钮、标签、分段、输入框统一用胶囊（pill）；列表项用 md；卡片用 lg；
内容面板、弹窗与便当格用 xl。

### 字体层级

| Token | 规格 | 字体 |
| --- | --- | --- |
| `display` | 30 / 700 | Space Grotesk |
| `headline` | 21 / 700 | Space Grotesk |
| `title` | 17 / 700 | Space Grotesk |
| `subtitle` | 15 / 700 | Space Grotesk |
| `body` | 14 / 400 | 默认 |
| `label` | 12 / 500 | 默认 |
| `caption` | 11.5 / 500 | 默认 |
| `overline` | 10.5 / 700，大写，字距 1.2 | JetBrains Mono |
| `mono` | 11 / 500 | JetBrains Mono |
| `dot` | 点阵数字 | Doto |

字体文件放在 `assets/fonts/`，均为 OFL 授权（许可证随附）。

### 动效与阴影

`UiMotion.fast` 120ms 用于悬停/按压，`standard` 180ms 用于位移类动画。
`UiShadows.popover / dialog` 用于菜单与弹窗；`UiShadows.glow(color)` 只给
"正在发生"的元素（直播胶囊、发送按钮）加一圈同色光晕。

## 3. Signal 组件

| 组件 | 说明 |
| --- | --- |
| `DotGridBackground` | 画布底色 + 点阵纹理 |
| `SignalTag` | 等宽大写小标签，如 `● LIVE · 3`，可填充或描边 |
| `EqualizerBars` | 静态均衡器竖条，表示"这里有人在说话"（不占用 ticker） |
| `DotCounter` | 点阵两位数字 + 等宽说明，用于大厅统计 |
| `BrandMark` | 酸橙方块里的耳机/气泡标识 |

基础组件约定：

- `PressableSurface`：唯一的可按压原语，扁平；静止 → 悬停（`hoverBackgroundColor`
  或自动提亮）→ 按压（压暗）。
- `Button`：neutral（深灰胶囊）、primary（酸橙实心深色字）、danger（暗红底红字）、
  `active`（白色反色）。`ButtonIcon(ghost: true)` 用于工具栏图标。
- `Input`：深色胶囊输入框，聚焦时出现酸橙描边与光圈；`bare` 用于嵌入式输入。
- `SegmentedControl`：黑色轨道内的白色反色选中块。
- `UiSwitch` / `UiCheckbox`：开启/选中为酸橙实心。

## 4. 信息架构

客户端没有侧边栏。整个窗口由"顶栏 + 一块内容面板"组成，房间像浏览器标签
一样排在顶栏里。

```
┌──────────────────────────────────────────────────────────────────────┐
│ ▣ GANG CHAT │ 大厅 │ 房间A ● │ 房间B 3 │ + ·····  ◉ LIVE 胶囊  ⌕ 🔔 ⚙ ◯ │
├──────────────────────────────────────────────────────────────────────┤
│ ╭──────────────────────────────────────────────────────────────────╮ │
│ │ 房间信息 · [聊天] 语音 成员 设置                                 │ │
│ │──────────────────────────────────────────────────────────────────│ │
│ │ 聊天流 / 语音舞台 / 成员 / 设置                                  │ │
│ ╰──────────────────────────────────────────────────────────────────╯ │
└──────────────────────────────────────────────────────────────────────┘
```

- **顶栏**（`home_shell_title_bar.dart`）：品牌字标、房间标签条
  （`HomeRoomTabStrip`，第一个标签固定为"大厅"）、正在连接的语音胶囊
  （麦克风/耳机/离开）、搜索、通知、设置、延迟信号与头像账号菜单、窗口按钮。
- **大厅**（`HomeLobby`）：便当格布局。左上是问候与点阵统计（房间 / 直播 /
  未读），旁边是"创建房间"格；正在直播的房间占两列，显示 `LIVE` 标签、
  在麦头像和均衡器；其余房间是紧凑卡片，显示最后一条消息或草稿。
- **搜索**：命令面板式浮层（顶栏搜索按钮打开，Esc 关闭），结果按分类分组。
- **房间**：内容面板顶部是 `RoomContextBar`——房间头像、名称、成员信息，以及
  反色胶囊分段 `聊天 / 语音 / 成员 / 设置`。
- **设置类页面**（个人设置、通知、房间成员、房间设置）：宽度 ≥ 720 时为双栏，
  左侧分区导航、右侧内容；窄屏为单栏并带返回按钮。

窄屏（< 720）：大厅以紧凑列表展示，底部是语音胶囊；进入房间后整屏显示
内容面板，顶部的 `RoomContextBar` 带返回按钮。

## 5. 聊天

- 扁平的消息流：同一发送者 5 分钟内的连续消息合并为一组，名称用展示字体，
  时间用等宽字体；悬停时整行轻微提亮。
- @我 的消息左侧有琥珀色竖线；未读分隔是红色胶囊"未读消息"；日期分隔是
  等宽小字。
- 输入栏是单行胶囊：附件、输入框、表情、语音与酸橙发送按钮；表情、贴纸等
  面板在输入栏上方展开。

## 6. 语音舞台

- 背景是从顶部散开的酸橙径向光；参与者以居中的圆形头像排开，说话时外圈亮起
  酸橙描边。
- 控制条悬浮在舞台底部（`_LiveControlDock`）：麦克风与耳机（含音量）、
  摄像头、屏幕共享、离开，以及"回到聊天"；未加入时主按钮为酸橙色的"加入语音"。

## 7. 音乐盒（Deck）

音乐盒是一台小型"播放卡座"：

- 顶部是点阵字标 `MUSIC BOX` 与当前来源芯片（点按跳到正在播放的列表）。
- **显示窗**：纯黑凹陷屏幕，带点阵纹理；左侧是状态标签（`NOW PLAYING` /
  `PAUSED` / `STOPPED`）、歌名（溢出时滚动）、艺人与点歌人；下方是由圆点
  组成的进度条，已播放部分亮起酸橙色，时间用点阵数字显示。黑胶唱片从屏幕
  右侧半露出来，播放时旋转，高光保持不动。
- **走带键**：模式 / 上一首 / 播放（双倍宽、酸橙色）/ 下一首，方形按键一字排开；
  无控制权限时显示一条锁定提示。
- **音量推子**：静音键 + `VOL` + 滑杆 + 点阵数值。
- **列表**：嵌在黑色底板里，三个"频道"按编号排列——`01` 点歌队列、
  `02` 房间歌单、`03` 我的歌单；曲目序号为两位等宽数字，当前曲目带酸橙描边。

## 8. 用户 / 房间名片（Pass）

悬停或点按头像弹出的名片做成一张"通行证"（`lib/src/home/profile_pass.dart`）：

- 顶部横幅取头像预设色，叠点阵网纹，左上角印 `GANG PASS · ONLINE` /
  `ROOM PASS · 公开` 之类的小字，右下角是放大的点阵 UID / RID 尾号。
- 头像压在横幅边缘，右侧是在线状态与身份徽章；下面是名字、@用户名、
  带酸橙竖线的签名或简介、共同房间 / 创建者等信息。
- 一条带半圆缺口的虚线"撕口"之后是存根：等宽的 `UID: …` / `RID: …`（可复制）、
  根据编号生成的条形码，以及主操作按钮。

## 9. 设置（Control Room）

- 顶部是返回、点阵标题 `SETTINGS`、**设置搜索**和刷新按钮。
- 下面是一排编号分区磁贴（`01 用户资料` … `07 关于`），每块磁贴显示该分区的
  当前状态摘要（如 `简体中文 · 每次询问`、`输入 80% · 输出 100%`、版本号）；
  选中的磁贴为白色反色。窄屏时磁贴横向滚动、只保留编号和名称。
- 搜索设置会在内容区列出匹配的条目（标注所在分区），点按直接跳到该分区。
- 分区内容是两栏表单：左栏是分组标题（带强调短线），右栏是控件面板；
  保存按钮按文字宽度右对齐。窄屏时标题移到面板上方。

## 10. 平台适配

- **macOS**：原生红绿灯由 `MainFlutterWindow.swift` 居中在 52px 顶栏内（左侧留
  19px），Flutter 顶栏左侧预留 92px（`window_chrome.dart`），品牌标识不会与
  红绿灯挤在一起。登录页在 macOS 上把标识放到字标左侧同一行，避开左上角的红绿灯。
- **Windows / Linux**：顶栏右侧为自绘窗口按钮。
