# Gang Chat UI 设计规范（Nocturne）

本文档描述客户端当前的视觉语言与版式结构。所有界面代码应只通过
`lib/src/ui/tokens.dart` 中的 token 取色、圆角、间距、阴影和动效，不再在
feature 代码里写死颜色值。

## 1. 设计原则

1. **扁平分层**：界面靠明度分层，不再使用"按键帽"式的立体底座。只有浮层
   （菜单、弹窗、Toast、悬浮卡片）使用阴影。
2. **单一强调色**：鸢尾紫（iris）是唯一的品牌强调色；成功/在线用翡翠绿，
   危险用玫瑰红，语音用青绿。不要为装饰引入新的色相。
3. **内容优先**：聊天、语音舞台等主内容放在圆角"内容面板"里；导航与工具
   退到更暗的画布上。
4. **人圆房方**：用户头像永远是圆形；房间头像是圆角方形（`Avatar(rounded: true)`）。
5. **克制的边框**：边框只用 1px 发丝线（`UiColors.border`），用来分隔同明度
   的区域；能用明度区分的地方就不要再加边框。

## 2. Token

### 颜色层级（由暗到亮）

| Token | 用途 |
| --- | --- |
| `surfacePressed` `#0B0C10` | 凹陷区域、轨道 |
| `background` `#0F1015` | 窗口画布：标题条、导航栏、房间列 |
| `surfaceLow` `#15161D` | 内容面板、设置页、弹窗 |
| `card` `#191A22` | 面板内的分组卡片 |
| `surface` `#1C1D26` | 卡片、列表项底色 |
| `surfaceRaised` `#252632` | 菜单、浮层、悬停 |
| `surfaceHover` `#2B2C3A` | 浮层内悬停、分段控件选中块 |
| `fieldFill` / `fieldBorder` | 输入框 |

强调色：`accent`（文字/图标用浅紫）、`accentStrong`（填充用的饱和紫）、
`selected` / `accentBorder` / `selectedBorder`（选中态底色与边框）。

语义色：`success`、`danger`、`amber`、`presence*`、`role*`。

### 形状

`UiRadii`：xs 4 · sm 6 · md 10 · lg 14 · xl 20 · pill 999。
按钮/输入框用 md，卡片用 lg，弹窗用 xl，标签/徽标用 pill。

### 字体层级

`UiTypography`：headline 20/700 · title 17/600 · subtitle 15/600 ·
body 14/400 · label 12/500 · caption 11.5/500 · overline 11/700（分组标题）。

### 动效与阴影

`UiMotion.fast` 120ms 用于悬停/按压，`standard` 180ms 用于位移类动画。
`UiShadows.raised / popover / dialog` 分别用于小浮起元素、菜单与弹窗。

## 3. 组件约定

- `PressableSurface`：唯一的可按压原语。静止 → 悬停（提亮）→ 按压（压暗），
  高度即视觉高度，不再额外占用"底座"空间。
- `Button`：neutral（灰底描边）、primary（饱和紫实心白字）、danger（暗红底）。
- `ButtonIcon(ghost: true)`：工具栏图标按钮，静止透明、悬停出底色。
- `Input`：凹陷输入井，悬停加深边框，聚焦为紫色边框 + 3px 光晕。
- `UiSwitch`：胶囊轨道 + 圆形滑块；`UiCheckbox`：选中时紫色实心。
- `SegmentedControl`：凹陷轨道内滑动的浮起选中块。
- 菜单/Toast/弹窗：`surfaceRaised` / `surfaceLow` + 发丝边框 + 阴影。

## 4. 主界面版式

宽屏（≥ 720）：

```
┌──────────────────────────────────────────────────────────────┐
│ 标题条：品牌标识 ······················ 拖拽区 ····· 窗口按钮 │
├────┬──────────────────┬──────────────────────────────────────┤
│导航│ 搜索             │ ╭──────────────────────────────────╮ │
│ 轨 │ 房间列表         │ │ 内容面板（圆角、发丝边框）       │ │
│    │                  │ │ 聊天 / 语音舞台 / 设置 / 通知 …  │ │
│    │ 语音连接卡片     │ │                                  │ │
│    │ 当前用户         │ ╰──────────────────────────────────╯ │
└────┴──────────────────┴──────────────────────────────────────┘
```

- **导航轨**：创建房间、通知、设置等全局入口，竖向排列。
- **房间列**：顶部搜索框（结果以浮层展开），中部房间列表，底部是语音连接
  卡片与当前用户卡片。
- **内容面板**：右侧圆角面板，所有内容页都渲染在其中。

窄屏（< 720）：房间列表页顶部为搜索，底部为语音卡片、用户卡片与导航条；
进入房间后整屏显示内容面板。

## 5. 聊天版式

- 头部为一条细的工具栏：房间头像（方形）、名称与成员信息、语音胶囊、成员
  与更多按钮，底部发丝线分隔。
- 消息流采用左对齐的"流式"排版：头像 + 名称行 + 正文，同一发送者的连续
  消息自动合并，正文不再使用气泡背景；@我 的消息用琥珀色左侧标记高亮。
- 输入区是一条浮起的输入栏：附件、输入框、表情、语音与发送按钮同在一行。
